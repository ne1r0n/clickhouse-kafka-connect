## Execution environment

- Branch `sync/v1.7.0`, main working tree. `custom_build` is protected: never checked out, committed to or pushed here.
- Gradle as `env -u TESTCONTAINERS_HOST_OVERRIDE ./gradlew ...`. A full run takes longer than the 10-minute foreground Bash cap: start it with `run_in_background`, write output to `/tmp/gsd15/` (outside `build/`, which `clean` deletes), record the exit code to a file, and poll.
- Docker: colima profile `vz` only (`colima stop --profile vz`, `colima start --profile vz`, `colima status -p vz`); never a bare `colima start`. Use the docker CLI by absolute path, `/opt/homebrew/opt/docker/bin/docker`, so a missing CLI can never masquerade as a stopped daemon.
- GitHub is read through the unauthenticated REST API (`gh` is deliberately absent): 60 requests per hour. Check `/rate_limit` (free) before polling; once the run id is known poll `/actions/runs/<id>` only, every 90 seconds, for at most 45 minutes; a response without a `workflow_runs` array (or without `status` for a single run) is an error, never "zero runs". Job logs return 403 without admin rights, so a red run needs the human to paste the failing log section.
- `origin` = `git@github.com:ne1r0n/clickhouse-kafka-connect.git`. At planning time: heads `custom_build` = `c61d90ce`, `main`, `sync/v1.7.0` = `54b5ce2f`; tags `pre-v1.6.0-sync`, `v1.6.0_gg1`.
