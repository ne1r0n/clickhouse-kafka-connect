## Decisions recorded in this plan

- **Where the pins live (D-05).** A new class in package `com.clickhouse.kafka.connect.sink`, so it uses `NullableRoundTrip`'s package-private helpers, and built on the spike's `RawNameMatrix` tables so the record and the pins describe the same DDL. `NullableTupleMatrixLiveTest` is not touched.
- **The doubled form.** It is `RawNameMatrix.doubledForm(name)`, which E-04's check c1 showed to be the exact form the pre-fix connector matched under client V2. Entries whose doubled form equals the raw form (`ctl`, `bt`, `na`, `ap`) have no doubled-form case; the method sources filter them by that equality, giving 8 entries.
- **Every Tuple shape for the element pin.** D-04's matrix covers four Tuple shapes, and the rollout statement "a Tuple element fails loudly" must hold for each, so the element pin is parameterized over the entry and the container (`tuple`, `array_tuple`, `nullable_tuple`, `map_tuple`).
- **The red proof restores the pre-fix production, not HEAD~.** The three files of `fix(28-03)` are written from `F^` into the working tree, the class runs, and `git checkout HEAD -- src/main` restores them. The predicted red set comes from E-04 by a stated rule, so a vacuous pin is caught.
- **Tracer.** Task 1 is this plan's tracer: the raw-form record through every layer the phase changed (DESCRIBE, the decode, pairing, the writer's name lookup) to a typed read-back.
- **The estimate (2026-10-23 revision, checker scope_sanity, accepted at low confidence).** 110k raw tokens at factor 1.0 with 0 calibration samples, so the figure is directional and 10% over the 100k budget. The plan is already a tracer and one expansion task with one test commit; its reads are whole files it needs (`NullableRoundTrip`, `RawNameMatrix`), and it reads no research file. Splitting the expansion off would add a plan's fixed reads (about 16k: the execute-plan workflow, the summary template and CONTEXT) and a re-read of the tracer's class to save about 10k here. Not taken. The 52 live cases run in one redirected Gradle call per step, read through one-line verify summaries.
