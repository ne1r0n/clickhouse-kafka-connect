<objective>
Stop the writer from logging record data on value-conversion failures (WRT-12, closing 13-SECURITY T-13-19), in two commits:

1. WRT-12 (D-08, D-12): a reusable reload4j log-capture helper and one shared masking helper for the DateTime and DateTime64 parse-failure logs. Each log carries the column name, ClickHouse type, Kafka type, exception class and value length, never the value or the parse exception's message. The unsupported-conversion `DataException` gains the column name.
2. D-09: the generic `catch (Exception e)` log in `doWriteColValue` names the column, the types and the exception class, with no throwable, and still rethrows the original. The residual (the rethrown message can carry the value) is recorded in FORK-DELTA and as backlog 999.3.

Each commit carries its own anchors, FORK-DELTA rows and ledger rows (D-13).

**Accepted residual. Acknowledge it when approving this plan (D-09, user-locked; T-18-07 `accept`).** After this plan, the `doWriteColValue` log line itself carries no data, but record values can still reach ERROR logs. The generic catch rethrows the original exception unchanged, and for some failures its message embeds the value: `UUID.fromString` gives `Invalid UUID string: <value>`, and number parsing gives `For input string: ...`. `doInsertRawBinary` then logs that exception with its throwable in its two `Error inserting records` ERROR lines, and the same message reaches the Connect task status and the DLQ headers. Phase 18 does not fix this. CONTEXT defers the fix, because changing the rethrown type or message must not change retry classification. Task 2 records it in FORK-DELTA Known costs item 6 and as ROADMAP backlog 999.3, and a test pins it, so a later fix has to change it deliberately.

Purpose: record values leave the connector through neither the DateTime / DateTime64 parse-failure lines nor the generic write-failure line, and not through their stack traces either. The rethrown-message path above remains open.

Output: two `fix(18-02):` commits on `sync/v1.7.0`; nothing pushed.
</objective>
