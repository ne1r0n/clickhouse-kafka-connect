- **Flake and drift rule, used by both tasks.** A failing test:
  1. Re-run its class alone with `--rerun` once.
  2. If it passes alone, run the full suite again. A pass there is recorded as a flake, with both outputs.
  3. If it fails alone, or fails in both full runs, restore the bumped line (`git checkout -- gradle/libs.versions.toml`) and re-run the class. Still failing means environment or `latest` drift, which is reported as such. Passing means the bump caused it, and D-05 applies.
- **D-05 stop.** Leave the edit uncommitted and return a `checkpoint:decision` with gate="blocking-human" and no auto_select. It names the failing test, the error text, the diagnosed cause and these options:
  1. adapt the test;
  2. hold the bump back;
  3. change main code.
  Never edit or delete a test.
