The path set is the sorted union of (i) the conflicted list printed by `git merge-tree --write-tree --name-only MERGE^1 MERGE^2` (skip line 1, which is the tree OID; stop at the first blank line) and (ii) `git diff --name-only MERGE^1 MERGE`. For each path present at MERGE (`git cat-file -e`), write the union of that path's content at MERGE^1 and MERGE^2 (each present side followed by one empty line) to a temp file. Count the lines of MERGE:path absent from that union with `LC_ALL=C grep -a -vxFf`. Any non-zero count prints `PROVENANCE VIOLATION: <n> authored line(s) in <path>`. The path loop MUST read on fd 3 (`while IFS= read -r p <&3; do ... done 3< <(...)`), because `git show` inside a plain `while read` loop eats the loop's stdin (RESEARCH Pattern 1 reproduced 30+ false violations).
(c) Conflicted-paths cross-check, only when CONFLICTED_PATHS_FILE is non-empty: the derived conflicted list must equal the sorted non-blank lines of `RANGE_END:CONFLICTED_PATHS_FILE`. A missing file or any difference prints `CONFLICTED-PATHS MISMATCH:`.
