## The rehearsal script (specification for Task 1, PL-7)

`49-rehearse.sh` is a bash script (`#!/usr/bin/env bash`, `set -uo pipefail`), run from the repository root as `bash ${RH} merge <TIP> <WORKDIR> [<MESSAGE_FILE>]` or `bash ${RH} at <COMMIT> <WORKDIR>`, with `MODE=attr` (default) or `MODE=plain` in the environment. It prints one `key=value` line per fact and, as its last line, `rehearsal: PASS` (exit 0) or `rehearsal: FAIL <keys that failed>` (exit 1); a usage error prints `USAGE ERROR: ...` and exits 2.

1. Preconditions (each a usage error): `<WORKDIR>` does not exist; `git show-ref --verify --quiet refs/heads/rollback-v1.7.0_gg8` fails (no such branch); `pre-v1.7.0_gg8` and `<TIP>` or `<COMMIT>` resolve to commits (the script replaces `<TIP>` and `<COMMIT>` by their full 40-hex SHA with `git rev-parse --verify '<arg>^{commit}'` before any use, so every printed SHA and every comparison is full-length); `<MESSAGE_FILE>`, when given, is read by its absolute path. It exports `GIT_AUTHOR_NAME`, `GIT_COMMITTER_NAME` (`rehearsal`) and `GIT_AUTHOR_EMAIL`, `GIT_COMMITTER_EMAIL` (`rehearsal@example.invalid`). `ATTR` is `--attr-source=<the empty tree id from git hash-object -t tree /dev/null>` in mode `attr` and empty in mode `plain`. A `trap` on EXIT removes the worktree (`git worktree remove --force`, `git worktree prune`) and deletes the branch `rollback-v1.7.0_gg8` if they still exist.
2. `merge`: `git worktree add --detach <WORKDIR>/d 9483476322e0d331e81c5b92ac266a18f0f01450`; in it `git ${ATTR} merge --no-ff -F <MESSAGE_FILE> <TIP>` (or `-m "Dry-run merge of <TIP> onto v1.7.0_gg7"` without a file). Prints `mode`, `start_commit` (the merge result), `merge_exit`, `d_commit`, `d_parents` (the parents of the merge, space-joined), `d_tree_equal` (`yes` when `git diff --quiet HEAD <TIP>`), `d_subject`. `at`: `git worktree add --detach <WORKDIR>/d <COMMIT>`; prints `mode`, `start_commit` (`<COMMIT>`).
3. In the worktree, both forms: `d_version` (the content of `VERSION`), `d_no_gsd_ws_arg` (`yes` when `.gsd-ws-arg` is absent), `d_allowlist_present` (`yes` or `no` for `.planning/scripts/confluent-archive-allowlist-v1.7.0_gg8.txt`), `d_baseline_tag` (`git tag --merged HEAD --list 'v*'` piped to the worktree's own `.github/scripts/baseline_tag.py` with `VERSION`'s content), `d_status_before_block` (`clean` or the porcelain lines `; `-joined).
4. The block: `python3 -I <absolute path of the main repository's 49-note-check.py> rollback docs/ROLLOUT-v1.7.0_gg8.md --print` run inside the worktree, written to `<WORKDIR>/block.sh`: `block_extract` (`ok` on exit 0), `block_sha256` (`shasum -a 256` of `<WORKDIR>/block.sh`, the hex only). Then `bash -e <WORKDIR>/block.sh` inside the worktree, stdout captured: `rollback_exit`, `rollback_output` (the last stdout line), `rollback_commit` (`git rev-parse HEAD`), `rollback_status_after` (`clean` or the lines), `gradlew_bat_trap` (`yes` when the status after the block lists `gradlew.bat`, else `no`), `rollback_version` (`VERSION`), `rollback_note_absent` (`yes` when `docs/ROLLOUT-v1.7.0_gg8.md` is absent), `rollback_tree_equals_tag` (`yes` when `git diff --quiet HEAD pre-v1.7.0_gg8`).
5. Forward again: `git ${ATTR} revert --no-edit <rollback_commit>`: `revert_exit`, `revert_restores_tree` (`yes` when `git diff --quiet HEAD <start_commit>`).
6. Clean up: remove the worktree, `git worktree prune`, `git branch -D rollback-v1.7.0_gg8`; `rehearsal_cleaned` (`yes` when the worktree directory and the branch are both gone). The script never pushes, fetches, creates a tag, or touches the main worktree's `HEAD`, index or files; the merge commit it makes stays unreferenced (`git gc` drops it).
7. PASS when: (`merge` only) `merge_exit=0`, `d_tree_equal=yes` and `d_parents` equal to `9483476322e0d331e81c5b92ac266a18f0f01450 <TIP>`; and in both forms `d_version=v1.7.0_gg8`, `d_baseline_tag=v1.7.0_gg7`, `block_extract=ok`, `rollback_exit=0`, `rollback_output=ok`, `rollback_version=v1.7.0_gg7`, `rollback_note_absent=yes`, `rollback_tree_equals_tag=yes`, `revert_exit=0`, `revert_restores_tree=yes`, `rehearsal_cleaned=yes`. `gradlew_bat_trap`, `d_allowlist_present` and `d_status_before_block` are recorded, not judged.
