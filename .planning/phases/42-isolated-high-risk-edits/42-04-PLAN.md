## Execution environment

The Execution environment section of `.planning/phases/42-isolated-high-risk-edits/42-01-PLAN.md` binds this plan unchanged. The rules this plan leans on most:
- Branch `sync/v1.7.0`, main tree, repository root; nothing reaches origin.
- **Throwaway worktree only.** The revert checks run in `$W/revert-wt`, a detached worktree created with `git worktree add --detach`. `git revert --no-commit` and `git reset -q --hard` run only there, always through `git -C $W/revert-wt`. The main tree keeps its uncommitted `.planning/config.json` and `.planning/state.json`; outside `.planning/` its `git status --porcelain` must be empty before and after. The worktree is removed with `git worktree remove --force` and `git worktree prune` at the end.
- zsh rules: write `${var}` before a colon or caret; never define a function `h`; call helpers as `python3 -I $X ...`; quote helper expressions that hold `?`, `~`, `^`, `>`, `#` or a space.
- `testUnit` in the worktree: `cd $W/revert-wt` inside a subshell, `rm -rf build/test-results/testUnit`, then the full `testUnit` recipe (Docker unreachable, `--rerun`, `-PjavaVersion=21`), log `$W/revert-c<i>-testunit.log`, copy to `$W/xml-revert-c<i>`. The first run compiles the worktree from scratch. Never overlap two Gradle runs. The JVM-crash rule applies.
- Long runs: never run the invariant script beside a Gradle run (it takes about 40 minutes); commit nothing while it runs.
- Commit rules and the evidence entry format as in 42-01. Only `$E` is staged in this plan.
- Names: `P`, `E`, `X`, `W`, `S`, `M`, `TS`, `PR`, `UT`, `CT`, `CFG`, `A`, `D2` as in 42-01; `C1`, `C2`, `C3` = the `code_commit` of E-03, E-06 and E-09; `WT=$W/revert-wt`; `T10` = E-10 `testunit_tests`.
