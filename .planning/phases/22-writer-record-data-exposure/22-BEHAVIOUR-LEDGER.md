# Phase 22 Behaviour Ledger

**Purpose:** one place that lists every operator-visible behaviour change made in Phase 22 (Writer Record-Data Exposure), so that Phase 24 can write the `1.7.0_gg3` CHANGELOG section, complete FORK-DELTA and write `docs/ROLLOUT-v1.7.0_gg3.md` (ROLL-03). Phase 22 writes no CHANGELOG, VERSION or ROLLOUT text.

**Source plans:** 22-03 (L-42..L-47), 22-04 (L-48; live pins added to L-42 and L-43)

**How to read it:** IDs continue after the Phase 19 ledger's L-41. Test references are `Class` or display-name prefixes. The ledger holds test names, decision IDs and message formats only, never record data.

**Destination key:** CHANGELOG = the `1.7.0_gg3` section of `CHANGELOG.md`; FORK-DELTA = a row or Known costs item; ROLL-03 = an item in `docs/ROLLOUT-v1.7.0_gg3.md`.
