## The JSON-route shapes (measured in Task 1, pinned in Task 2)

Every shape goes through `CapturingClickHouseWriter.doInsert(records, queryId, null)`, whose `doInsertJson` override calls the real `writeRecordsJson` and rethrows its `IOException` or `RuntimeException` unchanged. `S(x)` is a value implementing `com.fasterxml.jackson.databind.JsonSerializable` whose `serialize` (and `serializeWithType`) throws the scripted `x`; Jackson wraps a RuntimeException thrown there into a `JsonMappingException` with the reference chain. Measured in the first Task 1 run: `ObjectMapper.writeValueAsBytes` also wraps every non-Jackson IOException into a `JsonMappingException` with no cause (its message is `Unexpected IOException (of type <class>): <text>`), so no IOException without a Jackson link can leave the serialization statements; the no-Jackson control is therefore a RuntimeException that does not come from Jackson. A metadata-free serializer writes map keys itself, so a key never reaches a reference chain on those two routes and their value-carrying shapes put the sentinel in the scripted exception's message. Table column `payload`; topic `json-topic`, partition 0, offsets 0-2.

| Shape | Route | Value / failure |
|---|---|---|
| JSON_SCRIPTED_RUNTIME | SCHEMA_LESS (`Map` value) | `payload` = `Map.of("k", S(new RuntimeException("<SENTINEL>")))` |
| JSON_KEY_IN_REFERENCE_CHAIN | SCHEMA_LESS | `payload` = a map whose key is `<SENTINEL>` and whose value is `S(new RuntimeException("boom"))` (the key reaches Jackson's reference chain) |
| JSON_SCRIPTED_JACKSON_ALONE | SCHEMA_LESS | `payload` = `Map.of("k", S(new JsonMappingException("<SENTINEL>")))` |
| JSON_SCRIPTED_JACKSON_OVER_SOCKET_TIMEOUT | SCHEMA_LESS | `payload` = `Map.of("k", S(new JsonMappingException("<SENTINEL>", new SocketTimeoutException("timed out"))))` |
| JSON_NO_JACKSON_NULL_DATA_CONTROL (control) | DEBEZIUM_CDC, `bypassRowBinary=true` | a `Record` of schema type DEBEZIUM_CDC whose json map holds `payload` -> `null` (a null `Data`); the writer's own `v.getObject()` throws a `NullPointerException` before any serializer runs: no Jackson link, no value, so it must pass unchanged as the original exception object |
| JSON_SCHEMA_BYPASS_KEY | SCHEMA, `bypassRowBinary=true` | a Struct with a `Map<String,String>` field `payload`; after `Struct.put`, the map gains the key `<SENTINEL>` with value `S(new RuntimeException("boom"))` |
| JSON_METADATA_FREE_STRUCT_VALUE | SCHEMA, `insertFormat=json` (metadata-free, `MetadataFreeJsonWriter.structRow`) | a Struct with a `Map<String,String>` field `payload`; after `Struct.put`, the map gains the key `k` with value `S(new RuntimeException("<SENTINEL>"))` |
