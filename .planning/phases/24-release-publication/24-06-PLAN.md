## Execution environment

- **Who runs what.** A dispatched `gsd-executor` runs Task 1 and returns Task 2's checkpoint with the bundle. The user answers the orchestrator directly; the orchestrator, holding that answer, runs Task 3 **inline**. An executor refuses an approval relayed by another agent (Phase 11 lesson).
- **Fixed SHAs.** `P24_BASE = 07bf1e7695cc32fa7239b0b9ee0feed06c079f63`; `PRE = 6473e24f372a8b37dfd8cc8cf3124e6cff52edca` is `origin/custom_build` and must be an ancestor of the tip.
- **D-10 contingency.** If `origin/custom_build` is not `PRE` (a Dependabot merge slipped in), stop before using any gate result and return a `checkpoint:decision` (gate `blocking-human`) with the new tip and its commits. The locked recipe then applies, planned as a new plan: a DEPS-01-style merge into `sync/v1.7.0`, an exemption row if an anchored line moved (PR #9 would hit the BLD-08 `kafka = "4.1.1"` row), the D-08 diff and the note's dependency item redone, every gate re-run, and the rollback tag following the actual pre-merge tip.
- **Gradle.** `env -u TESTCONTAINERS_HOST_OVERRIDE ./gradlew ...`; the gate runs for many minutes, so run each long command with `run_in_background` and wait for its exit status (`test_gate_timeout` 2400 s). The anchors invariant takes about 10 minutes (research R8): background it.
- **Docker.** colima profile `vz` only: `colima stop --profile vz`, `colima start --profile vz`, `colima list`. The docker CLI by absolute path, `/opt/homebrew/opt/docker/bin/docker` (checked executable first, so a missing CLI cannot pass for a stopped daemon). Never a bare `colima start`.
- **OpenJ9.** An exit 255 is a JVM crash: read `javacore.*.txt`, delete `core.*.dmp`, `javacore.*`, `Snap.*.trc`, `jitdump.*` one by one (never `git clean`), re-run once, record both runs.
- **Floating `latest`.** `ClickHouseTestHelpers` pulls floating tags on every run. A red result on code that was green in plans 24-01 to 24-05: check the image date and `SELECT version()` first (memory, Phase 11), report, and do not edit tests to pass.
- **GitHub REST API**, unauthenticated, 60 requests per hour; `gh` is not installed. Check `/rate_limit` first. Poll `actions/runs?head_sha=<X0>` every 30-60 s for at most 5 minutes until the run registers, then `/actions/runs/<id>` every 90 s for at most 60 minutes. A body without `workflow_runs` is an error. Job logs need a token, and the Phase 17 Keychain item is gone (OPS-03): if log content is wanted (a red run), offer the user a new fine-grained read-only token (Actions: read, this repository only, 1-day expiry, stored by the user in the Keychain under a name they choose, read inline only, never printed or written) and record that it must be revoked afterwards (close record, Housekeeping).
- **Origin heads.** Dependabot may update `refs/heads/dependabot/*` at any time; every heads comparison excludes those refs and reports them.
- **Run counting.** Dependabot's dynamic workflow (`path` `dynamic/dependabot/dependabot-updates`) registers runs under the default branch tip's `head_sha` (seen on 6473e24f at planning time, beside its one `tests.yaml` run). Every run count in Phase 24 is therefore a count of runs whose `path` is `.github/workflows/tests.yaml`; runs of other paths are recorded, not counted.
- **What may change after the push.** Only `.planning/` (this plan's evidence and SUMMARY, STATE bookkeeping). Anything else re-opens plan 24-05 and needs a new rehearsal.
