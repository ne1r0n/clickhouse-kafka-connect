## Flagged assumptions

- **JSONP-07 (edge probe: unclassified).** This edge stays unresolved by design. The plan pins the null semantics as observed on ClickHouse 26.9.12.8 with the server's default `input_format_null_as_default=1`. An operator who sets that to 0 changes the non-nullable outcomes. That is an operator setting the connector deliberately does not force (D-02), and it is recorded for the Phase 15 rollout notes through L-08.
- DateTime and Date negatives are excluded from parity because both routes clamp or wrap them (RESEARCH Spike a2). This is a stated assumption, not a silent drop.
- A Kafka Date into a DateTime/DateTime64 column is excluded (D-17, ledger L-04).
