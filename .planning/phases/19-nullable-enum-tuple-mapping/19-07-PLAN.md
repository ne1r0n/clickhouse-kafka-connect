<objective>
Close the one failed truth in 19-VERIFICATION.md (SC3 / COLS-10, review CR-01). `DeclaredNullability.collect` reads nullability from the parsed node without unwrapping `SimpleAggregateFunction`. The pass therefore flips a Tuple element declared `SimpleAggregateFunction(f, Nullable(T))` from the correct `nullable=true` to `false`. The writer then drops that element's null marker and the RowBinary row silently misaligns. This plan fixes the leaf rule by unwrapping the wrapper the same way `Column.extractColumn` does. It pins the fix Docker-free and live on both twins. It also pins the one behaviour the entry-point unwrap changes beyond the leaf: a root `SimpleAggregateFunction(f, Tuple(...))` now pairs where it used to fall back. The anchors row, FORK-DELTA clause and ledger row land in the same commit (COLS-11). The `LowCardinality(Nullable(...))` and wrapper-boundary edge pins, the mutation and the adjacent-suite regression run are re-sliced into 19-09 to keep this plan within budget.

Purpose: removes the silent-corruption regression in the high-risk write path that blocks Phase 19 and, through it, the `v1.7.0_gg2` publication.

Output: one `fix(19-07):` commit (fix, CR-01 and root-wrapper pins, live class, bookkeeping). Nothing pushed.
