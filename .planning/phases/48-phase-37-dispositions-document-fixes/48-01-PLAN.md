## The two check scripts (specification for Task 2)

Both are Python 3 standard-library scripts, run as `python3 -I <script> REV DOC`, where `REV` is a commit or tag and `DOC` a repository path. Each reads `git show REV:DOC` (and `${PC}` also `git ls-tree -r --name-only REV`) through `subprocess` with a fixed argument list, writes no file, and exits 2 on a usage or git error. A module docstring states what the script checks, where its by-design list comes from, and that it is frozen after E-02.

`${PC}` (DOC-02), the FORK-DELTA evidence-path resolver:
1. Tokens: every match of the regular expression ``[^\s`()\[\],;|]+`` over the text; strip trailing `.`, `:`, `'` and `"` characters and leading `'` and `"` characters. Keep a token only when it starts with `.planning/`, `src/`, `docs/`, `.github/`, `build/`, `gradle/`, `scripts/` or `config/`, or equals `.gitattributes` or `.gitignore`. The candidates are the distinct kept tokens, each with the sorted set of line numbers where it occurs.
2. A candidate containing any of `<`, `>`, `{`, `}` is a placeholder: counted, not resolved.
3. A candidate whose text with trailing `/` removed equals one of `BY_DESIGN` is counted as by design, not resolved. `BY_DESIGN` is exactly these six, each with its reason in a comment: `.github/workflows/test-head.yaml` (upstream's file the fork deleted, FORK-DELTA records the deletion), `.planning/scripts/compare-confluent-archives.py` (the moved-from name of the compare script), `build/raw-name-matrix` (a generated, uncommitted build directory), `gradle/actions/setup-gradle` (a GitHub action name, not a path), `gradle/verification-metadata.xml` (absent by decision, FORK-DELTA item 18), `src/test/java/transforms/KeyToValueTest.java` (the fork's copy that was removed; the row names it as removed, U-10).
4. A candidate containing `...` is abbreviated: `.../` stands for zero or more whole directories; it resolves when exactly one tracked file at `REV` matches.
