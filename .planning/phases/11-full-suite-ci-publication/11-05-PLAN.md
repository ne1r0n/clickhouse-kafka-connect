<objective>
Rehearse the entire publication pipeline on a fully reversible branch, then assemble the evidence a human weighs at the one-way gate.

Purpose: 699 merged commits have never met a 2-core runner, a cold Gradle cache, or a freshly pulled floating `latest` image. `origin` has never seen this tree at all. The one-way publication push must not be the first time CI runs it — and this is also the first CI run since plan 11-02 removed the job-environment pins, so it is the first time CI has ever exercised the code defaults rather than routing around them.

Output: a green CI run on the scratch branch, located by `head_sha` plus workflow `path` with exactly one match; its wall-clock measured against a stated threshold; its coverage artifact confirmed; and D-03's six-item evidence bundle.

**On the tracer's position in this phase.** With `TRACER_MODE` on, a phase normally leads with its tracer. This phase deliberately does not: D-12 requires the local gate to run on the tree **as it will be published**, after plans 11-01, 11-02 and 11-03's edits, and D-02 requires the rehearsal to run on that same final tree. Rehearsing a tree that is not the one being published would prove nothing about the one that is. So task 1 below is the phase's tracer in the sense that matters — it is the **first slice on the irreversible path**, the thinnest thing that wires a local ref all the way through origin, the Actions trigger, the runner, the REST locator, the timing measurement and the artifact check, end to end — but it is not the phase's first task. That is a stated deviation, not an oversight.
</objective>
