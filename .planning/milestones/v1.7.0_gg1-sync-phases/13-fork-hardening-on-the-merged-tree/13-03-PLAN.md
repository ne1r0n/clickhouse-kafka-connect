<objective>
Make every nested null in RowBinary either round-trip or fail loudly (WRT-07, WRT-08). Pin that `Map(K, Nullable(V))` nulls already round-trip as NULL, with a mutation showing the pin has teeth. Then add the nested-null rules inside the container loops of `doWriteColValue`:
- nested null containers are coerced to empty (D-09);
- nested non-nullable scalar and Tuple slots throw a `DataException` that names the column with no data (D-10, D-12, D-16);
- top-level handling is left as upstream wrote it (D-11).

Purpose: today a nested null in a non-nullable slot writes a one-byte null marker into a fixed-width slot. That desyncs the RowBinary stream: the server either fails or, with a following row, can silently store garbage (RESEARCH Spike b).

Output: the writer change, Docker-free pins, a live test class, a dated REQUIREMENTS note for WRT-08, and ledger entries L-09..L-13.
</objective>
