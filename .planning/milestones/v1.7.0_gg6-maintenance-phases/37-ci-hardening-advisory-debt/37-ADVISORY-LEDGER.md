# Phase 37: Advisory ledger

This ledger closes the review rows of ADV-01 and ADV-02 as of the head `7f2b8268d8cc6c4a85f0158963d72913ef663069` (HEAD when plan 37-05 wrote it; the evidence entry E-16 of `37-COMMAND-EVIDENCE.md` records the measurements). It holds 29 base findings: the 7 of the Phase 30 review, the 6 of the Phase 31 review and the 16 findings of the Phase 29 close record that were still unfixed. A finding that needed two decisions is split into rows with a letter in parentheses, one status per part, so the table holds 36 rows for the 29 findings.

Status vocabulary: `fixed` means a fix landed in this phase and the pointer is the commit that carries it; `closed` means other work of this phase or an earlier one closed it and the pointer is that commit; `dispositioned` means the row is deliberately left as it is, the pointer is `-`, and the row carries an owner and a re-open trigger. The owner of every disposition is `fork maintainer (the user)`, except 30 IN-04, whose owner is Phase 38. A pointer is a 40-hex commit read from `37-COMMAND-EVIDENCE.md`, except the one pre-phase pointer of 25 IN-04 (d), which is the Phase 30 commit that closed it.

Phase 37 changes no file under `src/main` without the user's approval, and that approval has not been given. So the four findings that live in `src/main` (26 IN-02, 27 WR-01, 27 IN-01, 28 IN-01) and the null assertion of 28 IN-05 (tightening it changes an existing assertion) are dispositions; the owner decides whether any of them is worth the approval.
