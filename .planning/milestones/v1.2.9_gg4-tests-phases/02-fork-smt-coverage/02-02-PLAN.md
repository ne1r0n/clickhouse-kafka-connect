<objective>
Pin every unit-level behaviour of `HeaderToValue` (HDR-01..HDR-06) and close the stale
`valueSchema` cache that silently drops fields when a Debezium table's schema evolves mid-stream.

Purpose: `HeaderToValue` writes header-derived values into record fields that land in ClickHouse
columns. Its schema cache is built from the first record and never invalidated, so a mid-stream
schema change quietly rebuilds later records against the wrong schema — a real data-loss path for
the CDC pipelines this fork serves.

Output: the D-02 guard in
`src/main/java/com/clickhouse/kafka/connect/transforms/HeaderToValue.java`, and a grown
`src/test/java/transforms/HeaderToValueTest.java` carrying one named test per requirement ID.
</objective>
