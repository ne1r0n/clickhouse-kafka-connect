<objective>
Rebuild the test-source harness so ClickHouse-backed tests are fast and isolated:
- one shared `latest` container per test JVM fork, pulled with `PullPolicy.alwaysPull()` (INFRA-03, D-05)
- a fresh database per test class (D-08)
- Toxiproxy classes isolated on their own 23.8 container (D-07)
- a single inherited `@Tag("clickhouse")` (INFRA-04, D-12)
- a base-class MBean safety net plus an opt-in unique connector-name helper, proven by a deliberately failing test (INFRA-05, D-09, D-10)
- explicit UTF-8 decoding in test helpers, proven red-then-green (INFRA-06, D-11)

Purpose: Phases 2-4 add roughly ten new ClickHouse-backed classes. Without the singleton, each one pays a container start. Without per-class databases, table-mapping assertions (e.g. FILT-01) see other classes' tables. Without the sweep, one failing test leaks MBeans that distort Phase 4 JMX assertions.

Output: modified `ClickHouseBase`, both proxy test classes, `ClickHouseTestHelpers`; a new `ClickHouseTestHarnessTest`; and a green full suite on the new harness.
