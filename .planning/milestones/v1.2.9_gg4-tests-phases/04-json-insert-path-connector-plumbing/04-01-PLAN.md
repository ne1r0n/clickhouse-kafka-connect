<objective>
Pin the work-in-progress metadata-free JSON insert path exactly as it behaves today: the
`insertFormat=json` gate (JSON-01), table resolution without fetched metadata (JSON-02), the
`cleanupExtraFields` bypass (JSON-03), tombstone handling (JSON-04), and upgrade the two
pre-existing explicit-JSON tests from row counts to typed column-value assertions (JSON-05).

Purpose: this path ships in production CDC pipelines today and has effectively no behavioral
coverage — the two existing tests use **String** records, which route to `doInsertStringV2` and
never touch either metadata-free mechanism. Every test here is schemaless-Map-first per D-06,
because that is the only route where metadata-free mode actually changes behavior.

Output: one new ClickHouse-backed test class, one new Docker-free test class, typed assertions
added to the one existing fork-only test file, and a recorded developer decision on R-01's
silent-data-loss finding.
</objective>
