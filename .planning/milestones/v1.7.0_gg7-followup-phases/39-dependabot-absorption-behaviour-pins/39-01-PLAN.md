These rules bind every task in this plan (plans 39-02 to 39-04 repeat them).

- **Where.** Branch `sync/v1.7.0`, the main working tree, repository root as the working directory. Plans run sequentially on one tree. `custom_build` is never checked out or committed to.
- **Nothing reaches origin.** No `git push` of any branch or tag, no `gh` command, no REST call that writes. Reads use `git ls-remote`, `git fetch` of a named ref into `FETCH_HEAD` or `refs/remotes/origin/custom_build`, and unauthenticated `curl -sS --fail` GETs against `https://api.github.com/repos/ne1r0n/clickhouse-kafka-connect` (call it R). There is no scratch push in Phase 39: both PR heads already ran `tests.yaml` green on GitHub (research F2), and the first GitHub run of the combined tree is the Phase 44 rehearsal push.
- **Shell.** zsh. Write `${var}` before every colon or caret (`"${M}^1"`, `"${M}:gradle/libs.versions.toml"`); zsh reads `$M:g` as a modifier. Never name a variable `path`. Run multi-line logic under `/bin/bash -c` or `python3 -I`. There is no `timeout` binary.
- **Gradle.** Always `env -u TESTCONTAINERS_HOST_OVERRIDE ./gradlew --console=plain ...`; this shell sets that variable to the literal `null`, which breaks Ryuk. Every test run in Phase 39 uses `-PjavaVersion=21` (HotSpot 21 from Homebrew), so both runs of a pair share one JVM line and the OpenJ9 crash is avoided. Run `./gradlew --stop` before each suite. Never run `./gradlew wrapper`. Never run `git clean`.
- **Spotless, scoped only.** Never run `spotlessApply` or `spotlessCheck` over the whole tree: it carries 46 pre-existing violations that are not this phase's. The only Spotless use in Phase 39 is the scoped IDE-hook check of one touched Java file (plans 39-03 and 39-04): `env -u TESTCONTAINERS_HOST_OVERRIDE ./gradlew --console=plain -q spotlessApply -PspotlessIdeHook="$(pwd)/<file>" -PspotlessIdeHookUseStdOut > /tmp/gsd39/exec/sc.out 2> /tmp/gsd39/exec/sc.err`. With `-PspotlessIdeHookUseStdOut` it writes nothing to the tree; it exits 0 either way and prints `IS CLEAN` or `IS DIRTY` on a line of stderr, with the formatted file on stdout when dirty. The same command without `-PspotlessIdeHookUseStdOut` rewrites that one file only. Plan 39-01 touches no Java file.
