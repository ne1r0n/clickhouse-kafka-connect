## Decisions recorded in this plan

- **Fourth WRT-16 shape (research Open Question 3).** The fourth row is a plain `IOException` (`PLAIN_IO_CONTROL`), the literal roadmap shape, named inside the Jackson group so the four shapes read together. It duplicates `IO_PLAIN` on purpose. The alternative, a plain `IOException` whose cause is a Jackson exception, is not a WRT-16 row. Neither is a Jackson exception over a plain non-timeout `IOException`. A classification row cannot tell a pass-through from a conversion, because both outcomes are NON_RETRIABLE. Both shapes still pass through after WRT-17, so plan 27-02 pins each one as a same-instance accepted residual in WriterValueFreeFailureUnitTest and scopes the closure wording to match (27-02 decision "Accepted residual").
- **`JsonProcessingException` is realised as `JsonMappingException`.** In jackson-core 2.22.4 every `JsonProcessingException` constructor is `protected`. `JsonMappingException(String)` and `JsonMappingException(String, Throwable)` are public, and `JsonMappingException extends DatabindException extends JsonProcessingException extends JacksonException extends IOException` (javap, research). The project's Jackson is 2.22.4, not 2.21 (research F-8). Record both facts in E-02.
- **Tracer.** Task 1 is the phase's tracer: one Jackson row through every layer the phase touches, on the real path. Plans 27-02 to 27-05 are red-first edits of an existing end-to-end path and carry no tracer, as in the Phase 26 precedent (26-01 had the tracer, 26-02..26-05 were pin-first).
