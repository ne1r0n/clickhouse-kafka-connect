- **D-12 removes the counter instead of asserting it.** Nothing asserts it today, so removing it deletes no assertion. `isUseClientV2` keeps its override, because the writer branches on it.
- **The red-first proof shape for the premise loops (Claude's discretion, research Pitfall 8).** A code revert cannot show red, since the old loop is vacuous. - **The diff check's one exemption.** JsonAsStringKeyResidualLiveTest is the sanctioned flip (D-03, user sign-off, E-03, E-04). Its key-present helper was removed and its assert-call count may fall by one. It is exempt from the assert-count rule only; it must keep its 4 tests, its route-reached check and its no-row-landed check.

So E-13 carries a second table, `predicate changes to existing assertions`, with every existing assertion or assertion helper whose predicate changed. The table names the widened `assertJacksonRouteReached` (research F-1, E-04) as the phase's only wider predicate. The automated check requires each row, row (a)'s pointers, E-04's matching `signs_off:` and `seen_red:` lines, and the closing `no other predicate changed` line. The human check reads the table.
- **Not split, despite the 120k estimate (scope).** The estimate is low-confidence (no calibration samples), and most of it is live-test and full-suite output. The gate of Task 3 must run on the HEAD that holds the two DEBT-16 commits of Tasks 1 and 2, and it is the last step of the locked order. A split would add a plan boundary in front of the gate without lowering any task's cost. Every file in `files_modified` is edited.
- **The test-tree planning IDs stay (D-11).** The FixedString test's comment `Under WRT-13 (D-05)` and the premise message text `(IN-03 re-open trigger)` are kept verbatim. Scrubbing the test tree is deferred.
