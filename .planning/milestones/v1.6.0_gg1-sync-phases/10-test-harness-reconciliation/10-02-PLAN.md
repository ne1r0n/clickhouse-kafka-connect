<objective>
Run Phase 10's acceptance gate: the Docker-free `testUnit` task with the Docker daemon genuinely stopped, then two consecutive clean full `./gradlew test` runs against ClickHouse `latest` — the first full-suite evidence this milestone has taken on the server it claims to test.

Purpose: plan 10-01 made 25 test classes order-dependent within a fork for the first time, and Gradle's fork assignment varies from run to run, so one green run proves materially less here than it did in Phase 9. Separately, plan 10-01 moved the default server from a pinned LTS version to `latest`, which on this timeline means a major-version band change — the first live exercise of `DESCRIBE` behaviour for `JSON` and `Dynamic` sub-columns against a server nobody has run this suite on. D-06 gives this plan ownership of what `latest` surfaces, plus an attribution step so a server-version change cannot silently balloon a harness phase into a type-mapping phase.

Output: a recorded Docker-free green, two recorded full-suite greens with a named skip inventory and measured wall-clock, and — if `latest` surfaces anything — an attributed finding decided at a checkpoint rather than absorbed.
</objective>
