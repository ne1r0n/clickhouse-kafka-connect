<objective>
Drop the redundant job-environment pins from `.github/workflows/tests.yaml` so CI exercises the code defaults, and correct — in the same commit — the `ClickHouseTestHelpers` Javadoc sentence that asserts those pins exist (D-09).

Purpose: the server-version pin is what made the `latest` to pinned-LTS reversion **invisible from CI** for four phases. It kept CI green against the right server while every local gate silently moved to the wrong one, so CI structurally could not have reported the regression. `ClickHouseVersionDefaultUnitTest` is now the detector and it runs in CI too, so the pin is no longer protective — it is camouflage. Removing it is the correct reading of Phase 10's finding, not a loosening.

Output: a two-line `Run tests` step, a corrected Javadoc, and a Docker-free proof that the code default is what CI now resolves to.

Phase 10 deferred this decision here explicitly, and `MERGE-CHECKLIST.md` Recorded Fact 15 closes with it as the open Phase 11 question. This plan answers it.
</objective>
