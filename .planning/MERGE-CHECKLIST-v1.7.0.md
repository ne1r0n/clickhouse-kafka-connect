# Merge Resolution Checklist — `v1.7.0_gg1-sync`

This document is the checked-in, per-path and per-hunk resolution gate for the `custom_build` → `v1.7.0` merge (Phase 12, branch `sync/v1.7.0`, merge commit M = `54e6364858cd728e3427ce2058fc00380895c689`, rollback tag `pre-v1.7.0-sync` = `c61d90ce5dfb32ea5876dffacc8bb54d8846739a`). It sits beside `.planning/MERGE-CHECKLIST.md` (the v1.6.0 checklist, Recorded Facts 1-16), which stays as it is apart from one wording fix in plan 12-02.

Three rules govern it:

1. Section 1 is generated from `.planning/scripts/conflicted-paths-v1.7.0.txt` (the committed output of `git merge-tree --write-tree --name-only` over M's two parents), and Section 2 from `git diff --name-only refs/tags/v1.6.0 refs/tags/v1.7.0`. Neither is hand-transcribed. Section 2a has one row per hunk of `git diff -U0 refs/tags/v1.6.0 refs/tags/v1.7.0` restricted to the files the fork also changed.
2. It is a living gate (D-07). A status is `done` or `pending`, and a `pending` row names its owning phase (12 to 15) in the owning-phase column. Each owning phase flips only its own rows inside its own commits, and the closing plan or commit is named in the verdict, review or evidence column. Phase 15 asserts zero `pending` rows before publication.
3. Recorded Facts continue the global numbering at 17. Facts 1-16 are in `.planning/MERGE-CHECKLIST.md`, so a citation "Recorded Fact N" is never ambiguous.
